One line, in the router's own voice: the Wi-Fi router excuses itself for
dropping the connection at the exact climax of a movie — not with a buffering
apology, but with a smug little secret. It worked out the killer in minute
ten, and it refuses to sit through two hours pretending it didn't.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/router-out node main.ts
cat /tmp/router-out/entry.txt
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`) and self-checks it against the gate:
1–200 characters, a single non-blank line.
